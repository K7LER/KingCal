About KingCalendar

KingCalendar is a fully-featured VCL calendar component library for Delphi 10.2 through 13, supporting Win32, Win64, and Win64x platforms. Open source under the MIT License.

🗓

Full Month Grid

Renders a complete month view with day selection, blocked days, flagged days, and per-cell color customization.

🎨

9 Built-in Color Sets

Choose from nine named color schemes via ColorSet1–ColorSet9 properties, or build your own.

🔗

Companion Controls

Month/year/day spin and combo controls, week labels, a navigator panel, and a month-bar all bind directly to the calendar.

🪟

Popup & Dialog Modes

TKingPopup drops down like a date-picker; TKingDateDialog is a standalone date selection dialog.

🗄

Database Aware

TDBKingDlg links directly to a TField for seamless live binding in data-aware forms.

📐

High DPI & VCL Styles

Fully compatible with Delphi's High DPI scaling and VCL Styles runtime theming.

📦

No External Dependencies

Pure Object Pascal. Ships pre-compiled for every supported Delphi version — no third-party runtime required.

🔢

Spin Editors

Inline date, time, and MDY spin-button editors for quick keyboard-friendly date entry in any form.

Manual / Git

Clone the Repository

For developers who want the full source and prefer to manage builds themselves. Pre-compiled library files are included for every supported version.

  1. Clone the repo:
    git clone https://github.com/K7LER/KingCal.git
  2. In Delphi: Tools → Options → Library.
  3. Add LIBD<ver>x64\RELEASE to the Library Path.
  4. Add the source\ folder to the Browsing Path.
  5. Open packages\13\D13All.groupproj (adjust for your version).
  6. Compile the runtime package, then the design-time package.
  7. Right-click the design-time package → Install.

Project History

KingCalendar was originally created by Mark Lussier and AppVision in the mid-1990s for early versions of Delphi. In June 2018, Mark gave Lance Rasmussen of CDE Software in Seattle permission to open-source the component and publish it on GitHub. Lance has since modernized it for current Delphi versions, added High DPI and VCL Styles support, and built the automated installer. The library is released under the MIT License.
